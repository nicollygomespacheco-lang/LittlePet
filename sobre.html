Sobre o LittlePet

O LittlePet é um sistema de cadastro de animais criado para facilitar a organização de informações de pets e seus tutores.

O sistema permite armazenar informações como nome, espécie, raça, idade, sexo, cor, peso, tutor e telefone.

Objetivo

O objetivo do LittlePet é tornar o cadastro e a consulta de informações dos animais mais simples e organizada.

Funcionalidades

  • Cadastrar animais
  • Visualizar animais cadastrados
  • Editar informações
  • Excluir registros
  • Armazenar informações no MySQL
  • Validar o formulário com JavaScript

Informações cadastradas

Para cada animal, o sistema permite registrar dados básicos que ajudam na sua identificação e organização.
