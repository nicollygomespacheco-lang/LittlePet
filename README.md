# LittlePet
Sistema de cadastro e gerenciamento de animais desenvolvido como Projeto Integrado.

## Tecnologias
- Python
- Flask
- POO
- DAO
- SQLite
- HTML
- CSS
- JavaScript
- Fetch API

## Funcionalidades
- Cadastro de animais
- Listagem de animais
- Consulta de animal por ID
- Alteração de animais
- Exclusão de animais
- Integração entre front-end e back-end
- Armazenamento em banco SQLite
