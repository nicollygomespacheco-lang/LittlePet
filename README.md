# LittlePet

Sistema de cadastro e gerenciamento de animais.

## Sobre o projeto

O LittlePet é um sistema desenvolvido para cadastrar, consultar, editar e excluir informações de animais.

O projeto foi desenvolvido utilizando HTML, CSS, JavaScript, Python, Flask, POO, DAO e SQLite.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite
- POO
- DAO
- Fetch API

## Funcionalidades

- Cadastro de animais
- Listagem de animais
- Consulta de animal por ID
- Edição de animais
- Exclusão de animais
- Integração entre front-end e back-end

## Estrutura

### Front-end

HTML, CSS e JavaScript.

### Back-end

Python com Flask.

### Banco de dados

SQLite.

## API

### Listar animais

GET `/animais`

### Cadastrar animal

POST `/animais`

### Buscar animal

GET `/animais/<id>`

### Atualizar animal

PUT `/animais/<id>`

### Excluir animal

DELETE `/animais/<id>`
